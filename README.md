# 📝 Taskly – Task Management Application

Taskly is a full-stack **task management web application** that allows users to efficiently organize their work by creating tasks with **priority levels**, **status tracking**, and **color indicators**.  
It helps users stay productive by visually managing tasks based on importance and progress.

---

## ✨ Features

- 🔐 User authentication (Login & Signup)
- 🛡️ Secure protected routes using JWT
- ➕ Create tasks with:
  - Priority levels: **High, Medium, Low**
  - Color-coded tasks for better visibility
- 🔄 Update task status:
  - Pending
  - In Progress
  - Completed
- ✏️ Edit and delete tasks
- 📋 View task details
- 📱 Fully responsive user interface



---
